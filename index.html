The strip

How it works. Every app builds a text state and a typed question (a Choice with described options, a yes/no Noul, or a Score), posts it to the model's /v1/systemone endpoint straight from your browser, and plays the answer. No server sits in between. Rides you drive are stored in this browser's storage; export them to share. No rankings yet, just the playground and the playbacks.

Bringing your own car

A car is any server that speaks TypeSafe's POST /v1/systemone: decider, JevK5, imajev, or TypeSafe's own Jev with your key.

The browser talks to it directly, so the server must allow cross-origin requests from this page. Model servers do not, and an https page like this one may only reach 127.0.0.1 through a server that also answers Chrome's private-network check. The tiny relay that ships with this site (tools/jevst-proxy.py, standard library only) does both. Run it next to your server and point the car at it:

python3 tools/jevst-proxy.py --target http://127.0.0.1:8001 --port 8765

Then set the car's URL to http://127.0.0.1:8765. Chrome may ask once whether this site may reach your local network; allow it.

TypeSafe's API refuses browser calls, so the TypeSafe car goes through this site's own hop at /ts: a Cloudflare function that forwards your request and key to api.typesafe.ai and keeps neither. The key itself stays in this browser. Every request is billed to it.

PostHog's AI gateway serves JevK5 as posthog/hogference/jevk5-fp8-0.2 on the same /v1/systemone route, and it does allow browser calls, so that car talks to gateway.us.posthog.com (or gateway.eu.posthog.com) directly with a project secret key that has the llm_gateway:read scope. PostHog is still rolling the decision route out; until it is enabled for your project the check reports that plainly. Requests are billed to your gateway wallet.

Someone else's car is a public endpoint they gave you: paste its URL, same as your own.

HN triage

      

        

          

          

          
route to review when the topic's top probability is under0.55

          

          
Every new Hacker News submission (public API, read straight from your browser) is one request with four typed questions answered from the same forward pass: topic (8 options), kind (6 options), front-page appeal (yes/no) and technicality (3 levels). A topic probability under the threshold sends the story to the review lane instead of auto-filing it. The feed lives only for this page visit.

Calibration

      

        

          

            

            

          

          
hindsight horizon10 decisions

          

          
Every recorded decision carries the probability the model put on the move it played. Hindsight buckets those probabilities and shows how often the game did not end badly (crash, loss, game over) within the horizon: a survival curve that should rise with confidence. Forced moves (Connect Four) is real correctness: positions with an immediate win or a forced block, and whether the model played one; its gap to the diagonal is the calibration error. Bars behind the curves are how many decisions fell in each bucket. Computed over the bundled rides plus yours, in this browser.
